# Security reports

Do not post secrets, private project content, customer media, or exploit
details in a public issue.

For a security-sensitive LitSquare Stage report, open a minimal redacted issue
at <https://github.com/thierryc/litsquare-stage-integrations/issues> and ask
Thierry Charbonnel to arrange a private follow-up. Include only product
version, affected surface, and a safe high-level description.
