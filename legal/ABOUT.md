# About LitSquare Stage

**Code-first motion. Native rendering.**

LitSquare Stage is a local macOS companion for creating, reviewing, and
rendering deterministic code-first motion with Codex, Claude Code, Cursor, and
other standards-based MCP clients.

## Build 17

- Native app: `0.9.5 (17)`
- Codex and Claude integration package: `0.9.6`
- npm runtime: `@litsquare/stage@0.1.1`
- Platform: Apple Silicon
- Minimum system: macOS 26
- Local MCP endpoint: `http://127.0.0.1:7460/mcp`

The native app renders projects and writes artifacts on the Mac. The MCP
listener binds only to loopback and does not provide a remote-binding option.
